# Розпізнавання жестів руки за sEMG для біонічного протеза

Прототип модуля розпізнавання жестів для магістерської роботи «Біонічний протез руки з
системою розпізнавання жестів на основі нейромережі». Модуль приймає вікно поверхневої
ЕМГ із 8 каналів браслета (200 мс) і повертає один із 6 жестів з упевненістю.

Модель — невелика 1D-CNN (34 086 параметрів), навчена на публічному датасеті
[UCI EMG Data for Gestures](https://archive.ics.uci.edu/dataset/481/emg+data+for+gestures).
**Реального датчика в проєкті немає**: потік емулюється з записів датасету.

## Жести

| gesture_id | gesture_name |
|---:|---|
| 1 | спокій |
| 2 | кулак |
| 3 | згинання зап'ястя |
| 4 | розгинання зап'ястя |
| 5 | радіальне відхилення |
| 6 | ульнарне відхилення |

Номери збігаються з класами датасету. Клас 0 датасету («без розмітки»: паузи між
жестами) і клас 7 (розкрита долоня, є лише у двох учасників) модель не розпізнає.

## Використання

```python
from gesture_recognizer import GestureRecognizer

rec = GestureRecognizer()            # завантажує models/best_cnn.pt
result = rec.predict(window)         # window: numpy-масив [40, 8]
```

Вимоги до `window`:

- форма `[40, 8]`: 40 відліків × 8 каналів, тобто 200 мс при 200 Гц;
- сигнал **уже відфільтрований** (смуговий 20–90 Гц + режекторний 50 Гц) і **не
  нормалізований**, бо нормалізацію з train модель застосовує сама;
- для потоку використовуйте `emg_stream.CausalWindowFilter`: він фільтрує лише нові
  відліки кожного вікна й зберігає стан між вікнами.

Неправильна форма або NaN дає `ValueError` з поясненням (зокрема підказку, якщо осі
переставлені як `[8, 40]`).

### Формат повідомлення

`predict` повертає словник; у JSON (`json.dumps(result, ensure_ascii=False)`) він має
такий вигляд. Це реальний вихід для вікна з жестом «кулак» (учасник 9, серія 1,
t = 5,1 с, значення округлено):

```json
{
  "gesture_id": 2,
  "gesture_name": "кулак",
  "confidence": 0.9996,
  "probabilities": {"1": 0.0, "2": 0.9996, "3": 0.0004, "4": 0.0, "5": 0.0, "6": 0.0}
}
```

- `gesture_id`: int 1–6;
- `gesture_name`: str;
- `confidence`: ймовірність обраного жесту, 0–1;
- `probabilities`: ймовірності всіх 6 жестів, у сумі 1. У Python ключі — int, у JSON — рядки.

### Демо в реальному часі

```bash
python demo.py --speed 10                       # перший test-учасник, серія 1, у 10 разів швидше
python demo.py --subject 9 --series 2 --speed 1
```

Запис програється через `EMGStreamEmulator` (вікно 200 мс, крок 50 мс) і фільтрується
каузально. Друкуються зміни розпізнаного жесту, упевненість, затримка обробки та мітка
датасету. Наприкінці — статистика затримки й accuracy на розмічених вікнах.

### mock_predictions.csv

`results/mock_predictions.csv` — прогнози в тому вигляді, в якому їх видавав би потік.
Файл можна використати для розробки протеза без моделі й даних. Згенерувати заново:

```bash
python gesture_recognizer.py
```

| колонка | опис |
|---|---|
| `timestamp` | секунди від початку потоку, коли надійшов останній відлік вікна (перше вікно — 0,2 с, далі крок 0,05 с) |
| `gesture_id` | розпізнаний жест 1–6 |
| `confidence` | упевненість 0–1 |

Потік складається з серії 1 шести test-учасників (2, 3, 9, 14, 15, 35), програних
підряд. Прогноз видається для кожного вікна, зокрема під час пауз між жестами.
Інтервали часу кожного учасника записано в `results/mock_predictions_meta.json`.
Усього 7 187 рядків, 360,4 с потоку.

## Результати

Усі числа взято з `results/*.csv`; повні таблиці — у
[docs/results_tables.md](docs/results_tables.md). Test — учасники, яких модель не бачила
під час навчання (розбиття за учасниками, `results/split.json`).

| модель | test accuracy | test macro-F1 | джерело |
|---|---:|---:|---|
| 1D-CNN (`models/best_cnn.pt`) | 0,771 | 0,767 | `results/cnn.csv` |
| SVM-RBF на ознаках MAV/RMS/WL/ZC/SSC | 0,779 | 0,775 | `results/baseline.csv` |

- На трьох інших розбиттях 24/6/6 macro-F1 SVM становив 0,846 ± 0,030, а CNN —
  0,816 ± 0,032 (`results/exp1.csv`).
- Якщо навчати на першій серії самого учасника, macro-F1 на його другій серії в
  середньому 0,859 (CNN) проти 0,720 при навчанні на інших людях (`results/exp2.csv`).
- Затримка: інференс CNN на CPU займає 0,120 мс на вікно (`results/cnn.csv`), тож
  затримку рішення визначає довжина вікна (200 мс).
- У потоковому прогнозі accuracy на 2 083 розмічених вікнах серії 1 test-учасників
  дорівнює 0,811 (`results/mock_predictions_meta.json`).

## Відомі обмеження

- **Публічні дані, а не власний датчик.** Модель навчена на записах браслета Myo з
  датасету UCI. Зі своїм датчиком (інші електроди, підсилення, частота, розташування)
  без перенавчання вона, найімовірніше, працюватиме гірше.
- **Немає реального потоку.** Потік емулюється з файлів. Реальні затримки зв'язку,
  втрати пакетів і шум не моделюються.
- **Частота даних.** У файлах рядки йдуть ~1 кГц, але значення оновлюються лише
  ~100 разів/с (деталі в [docs/datasets.md](docs/datasets.md)). Модель працює на
  сітці 200 Гц.
- **Точність на нових людях обмежена.** Macro-F1 на test близько 0,77, із великим
  розкидом між людьми: для окремих учасників і 0,50 (`results/exp2.csv`).
  Найчастіше плутаються кулак зі згинанням зап'ястя та розгинання з ульнарним
  відхиленням (`results/confusion_CNN_1D.png`).
- **Прогноз «мерехтить».** Між сусідніми вікнами (крок 50 мс) жест часто змінюється.
  Згладжування (голосування за кількома вікнами, поріг упевненості) немає.
- **Немає класу «пауза/невідомо».** Під час пауз між жестами модель однаково видає
  один із 6 жестів.
- **Розбіжність фільтрів.** Модель навчена на нуль-фазово відфільтрованих даних
  (`sosfiltfilt`), а в потоці фільтр каузальний.
- **Оцінка оптимістична.** Test містить лише вікна без зміни жесту, а серії одного
  учасника, ймовірно, записані в одній сесії.

## Структура

| шлях | що це |
|---|---|
| `gesture_recognizer.py` | `GestureRecognizer`, `make_mock_predictions` |
| `emg_stream.py` | `EMGStreamEmulator` (емуляція потоку), `CausalWindowFilter` |
| `demo.py` | демо в реальному часі |
| `models/cnn.py`, `models/best_cnn.pt` | архітектура та навчена модель (ваги, нормалізація, класи) |
| `emg_data.py`, `emg_preprocess.py`, `emg_features.py` | завантаження, фільтрація, ознаки |
| `experiments/` | baseline, навчання CNN, експерименти |
| `docs/` | інвентаризація даних, таблиці результатів, нотатки для диплома |
| `results/`, `figures/` | CSV і графіки |

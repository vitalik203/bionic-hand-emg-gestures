# Диплом (магістратура)

Тема: «Біонічний протез руки з системою розпізнавання жестів на основі нейромережі».
Мета: класифікація жестів за поверхневою ЕМГ, затримка ≤ 200–300 мс, стійкість до нових користувачів.
Дані: UCI EMG data for gestures (id 481), 36 піддослідних, Myo, 8 каналів, ~200 Гц (ще не перевірено).
Використовуємо класи 1–6; клас 0 («без розмітки») ігноруємо, клас 7 є не в усіх.
Стек: Python 3.11+, numpy, scipy, pandas, scikit-learn, matplotlib, seaborn, torch, pytest. Працює на CPU і в Google Colab.
Правила:

- Розбиття train/val/test ТІЛЬКИ за піддослідними; нормалізацію вчимо лише на train.
- Фіксоване зерно випадковості; результати експериментів пишуться в results/ (CSV + PNG).
- Код з типами, докстрінгами та pytest-тестами. Докстрінги й коментарі українською.
- Не вигадуй числа й літературу. Якщо чогось не перевірив, так і скажи.
